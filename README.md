# Alaa Atef Elesily — Liquid Glass Portfolio

A full visual redesign with:
- Premium liquid-glass / frosted-glass UI
- Dark + light mode
- Animated portrait scene with 3D hover tilt
- Ambient particles and floating glass chips
- Responsive mobile navigation
- Existing page structure: Home, About, Contact, Links, Tools
- Separate HTML / CSS / JS files

## Deploy
Upload the contents of this folder to the root of the `alaaatefelesily.github.io` repository and enable GitHub Pages from the repository's Pages settings.
